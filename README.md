# Neovim Modular Config (2026)

A clean, modular, and high-performance Neovim configuration built with lazy.nvim.

## Features / ویژگی‌ها
- **Modular structure:** Organized core, plugins, and LSP settings. / ساختار ماژولار: تفکیک تنظیمات هسته، پلاگین‌ها و LSP.
- **Performance:** Fast fuzzy finding with fzf-lua. / عملکرد بالا: جستجوی سریع فایل‌ها با fzf-lua.
- **Modern Navigation:** File management with oil.nvim. / ناوبری مدرن: مدیریت فایل‌ها با oil.nvim.
- **LSP Ready:** Automatic setup via Mason. / آماده‌سازی LSP: تنظیم خودکار سرورها توسط Mason.

## How to use / نحوه استفاده
1. Clone this repo into ~/.config/nvim. / ریپوزیتوری را در مسیر ~/.config/nvim کلون کنید.
2. Open Neovim, it will automatically install plugins. / نئوویم را باز کنید تا پلاگین‌ها به صورت خودکار نصب شوند.
